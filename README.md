# Invite Bot

Telegram-сервис инвайтинга в группы: aiogram 3 (интерфейс) + Telethon (воркеры) + SQLite.

## Возможности
- Подписка на срок — инвайтинг без лимита приглашений, пока подписка активна.
- Каждый пользователь подключает свои аккаунты: по номеру (код набирается кнопками, 2FA) или файлом `.session`.
- Двухэтапный инвайт: контакты → пауза → приглашение; ротация аккаунтов при FloodWait / спамблоке.
- Оплата по реквизитам: карта (грн), USDT (TON / TRC20 / ERC20 / BEP20), BTC.
  Карта и TON — автоматический MEMO, остальные сети — уникальная сумма. Курсы BTC и гривны обновляются сами.
- Админ-панель: тарифы, промокоды, реквизиты, заявки на оплату, выдача подписки, статистика, премиум-эмодзи.

## Запуск
```
pip install -r requirements.txt
copy .env.example .env   # BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS
python main.py
```
Дальше: `/admin` → Реквизиты (адреса) → Тарифы.

## Структура
- `bot/handlers/` — user, accounts, payments, admin
- `bot/keyboards.py`, `bot/ui.py` — кнопки и эмодзи
- `core/telethon_engine.py` — инвайт, пул аккаунтов, вход по номеру
- `core/queue_manager.py` — очередь задач (`asyncio.Queue`), прогресс
- `core/rates.py` — автообновление курсов
- `database/` — модели SQLAlchemy 2.0 и запросы
